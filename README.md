# CSV集計ツール

CSVを集計して、CSV・Excel(xlsx)・PDFに出力するツールです。
Python で作っています。

## 作った理由

実務に近いものを作成したいと思い、売上のようなCSVデータを手作業で集計する手間を減らすツールを作りました。
フォルダにCSVを入れて実行するだけで、店舗別・商品別の合計が3つの形式で出力されます。
（公開用のデータは、実際の業務とは関係のないダミーです）

## 使っている技術

- Python 3
- csv / pathlib（標準ライブラリ）
- openpyxl（Excelファイルの出力）
- reportlab（PDFの出力）
- PyInstaller（exe化）

## 動かし方

```bash
pip install -r requirements.txt
python aggregation.py
```

1. `集計したいcsv` フォルダに、集計したいCSVファイルを入れる
2. `python aggregation.py` を実行する
3. `集計後` フォルダに、結果が出力される

`集計したいcsv` には、動作確認用のダミーデータが入っています。

### 入力するCSVの形

1行目が見出しで、次の列があるCSVを想定しています。

```
日付,店舗,商品,数量,単価,金額
2026/10/2,A店,ノート,10,120,1200
```

## 出力

`集計後` フォルダの中に、形式ごとのフォルダができます。

```
集計後/
  csv/    店舗_sales_1.csv, 商品_sales_1.csv ...
  xlsx/   店舗_sales_1.xlsx, 商品_sales_1.xlsx ...
  pdf/    店舗_sales_1.pdf, 商品_sales_1.pdf ...
```

「店舗ごと」と「商品ごと」の合計（単価 × 数量）を、金額の大きい順に出力します。

| 名前 | 合計 |
|---|---|
| A店 | 25740 |
| C店 | 19320 |
| B店 | 15110 |

## 工夫した点

- フォルダの中のCSVを、`glob` で全部見つけて、1つずつ処理します
- 文字コードは `utf-8-sig` で読み、読めなかったときは `cp932`（ExcelのCSV）でやり直します
- 列名が違うファイルや、数値が不正なファイルは、止まらずにスキップして、ほかのファイルの処理を続けます
- 集計の部分は共通にして、出力の部分（`save_csv` / `save_xlsx` / `save_pdf`）だけを分けました
- 出力先のフォルダは、なければ自動で作ります
- PyInstaller で exe にして、ダブルクリックで動くようにしました
